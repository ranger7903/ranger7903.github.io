무료로 드리는 도구

회원가입도, 메일도, 정품 키도 필요 없습니다. 그냥 받아 가세요.

목록을 불러오는 중입니다…
받는 데 시간이 조금 걸립니다. 파일이 커서 여러 조각으로 나눠 받은 뒤, 하나로 합치고 원본과 같은지 스스로 확인한 다음에 저장됩니다. 다 될 때까지 이 창을 닫지 말아 주세요.
받으실 때·여실 때 윈도우가 한 번 막습니다 — 고장이 아닙니다.
밸류스는 아직 마이크로소프트에 내는 서명을 사지 않아서, 윈도우가 "처음 보는 만든이"라며 경고를 띄웁니다.
· 받을 때 — 크롬 아래쪽 ⋮ → 계속 (엣지는 … → 유지)
· 열 때 — 파란 창에서 추가 정보 → 실행
왜 그냥 드리나요?
이 세 가지는 비슷한 일을 하는 공짜 도구가 이미 많습니다. 그런 것에까지 값을 받는 것은 저희 생각에 맞지 않아서, 값을 내리는 대신 아예 무료로 돌렸습니다.
써 보시고 마음에 드시면 다른 도구도 한 번 봐 주세요.
