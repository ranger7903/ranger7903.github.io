📊 Getting a table out of a PDF into Excel

If you are retyping tables out of PDFs by hand — you don't have to. Here are three ways that cost nothing. One of them usually works.

First — which kind of PDF is it?

Ten seconds saves an hour. Open the PDF and try to drag-select the text in the table.

  • The words highlight in blue → it is a text PDF. All three methods below work.
  • Nothing highlights, or a whole rectangle is selected like a picture → it is an image PDF (a scan). To the computer it is a photo, so copying gives you nothing. Jump to “When it is a scan”.

Method 1 — let Excel read it (the cleanest)

Excel → Data → Get Data → From File → From PDF

Pick the PDF and Excel lists the tables it found on each page. Choose one and press Load. The columns are split for you.

Don't see that menu?

It arrived with Microsoft 365 and Excel 2021. Excel 2016 and 2019 do not have it — use method 2.

Method 2 — copy, paste, then split the columns

  1. Select the table in the PDF and copy (Ctrl+C).
  2. Paste into Excel (Ctrl+V). Often each row lands in a single cell.
  3. Select that column → Data → Text to Columns → Delimited → tick Space or Comma → Finish.

If leading zeros vanish or numbers turn into dates, set that column to Text on the last step.

Method 3 — go through Word first

Word can open a PDF and often rebuilds the tables as real tables. Copy the table from Word and paste it into Excel — the columns come across intact.

Right-click the PDF → Open with → Word

Tables with many merged cells often come out twisted this way. Look it over after pasting.

Where all three usually go wrong

This kind of tableWhat happens
Merged cellsThe merge comes apart and every row below shifts by one
A long table over several pagesThe header row repeats on every page and has to be deleted
Numbers with commas1,234 arrives as text, so it won't add up
Cells with two linesOne cell splits into two rows

Two or three tables, you can fix by eye. Thirty or a hundred, and it becomes a job.

When it is a scan (image PDF)

You need text recognition (OCR) first. It is never 100% — it mixes up 0 and O, 1 and l. For money or head counts, always check against the original.
