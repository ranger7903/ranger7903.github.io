🏅 One template, many certificates

If you are making thirty certificates by changing the name and saving thirty times — you don't have to. Word can do it for free.

1 — Get the list into a table

In Excel, make a table whose first row is the column names. That is all.

Name Department Award John Smith Accounting Excellence Mary Jones Marketing Merit

The first row (Name, Department, Award) becomes the names of the blanks in your template. Avoid empty rows and merged cells — keep it a clean rectangle.

2 — In Word: Mail Merge

Open your certificate in Word → Mailings → Select Recipients → Use an Existing List → choose the Excel file → put the cursor where the name goes → Insert Merge Field → Name → do the same for Department and Award → Preview Results and step through → Finish & Merge → Edit Individual Documents — thirty pages in one file
Always preview

Look at the first page and the last. Lines that shift or a name that wraps onto two lines almost always show up first with the person who has the longest name. Finding it after printing thirty sheets wastes paper.

3 — Where it usually breaks

What you seeWhy, and the fix
Dates come out in the wrong formatThe raw date value came through. Easiest fix: turn the date into text in Excel first (e.g. 27 September 2026)
Numbers grow long decimalsSame reason. Turn amounts and counts into text in Excel first
A name wraps onto two linesOne long name. Shrink the font a little in that spot, or widen the box
Someone's page reads oddlyA blank cell in the list leaves a hole in the sentence. Fill the list first

4 — The limits of this method

  • One separate file per person takes a lot of extra clicks — Mail Merge joins everything into one file by default.
  • Naming each file after the person (“John Smith_Excellence.pdf”) is not something the built-in feature does.
  • With two or three templates (certificate, completion, confirmation letter) you start over each time.
