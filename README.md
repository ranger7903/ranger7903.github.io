경주에서 한 사람이 만듭니다. → **[valuestools.kr](https://valuestools.kr/)**

이 저장소는 그 홈페이지(valuestools.kr)의 내용입니다.

---

## 밸류스가 지키는 것

- **인터넷을 쓰지 않습니다.** 모든 도구가 손님 컴퓨터 안에서만 일합니다. 서버가 없고, 파일을 어디로도 보내지 않습니다. 인터넷 선을 뽑아도 똑같이 움직입니다.
- **구독이 없습니다.** 한 번 사면 기간 제한 없이 쓰시고, 같은 판(v1.x) 업데이트는 무료입니다.
- **광고가 없습니다.** 공짜로 드리는 앱에도 다른 회사 광고가 한 줄도 없습니다.
- **후기를 고쳐 싣지 않습니다.** 별이 낮아도 그대로 싣거나, 아예 안 싣거나 둘 중 하나입니다.

---

## 도구를 사지 않으셔도, 이대로 하시면 됩니다

저희가 도구로 대신해 드리는 일을 **손으로 하는 법**도 그대로 적어 두었습니다.
읽고 혼자 하셔도 좋습니다.

- **[공문서, 이대로만 쓰면 안 틀립니다](https://valuestools.kr/gongmun-guide.html)**
  — 「끝.」은 어디에 찍는지, 붙임은 몇 칸 띄우는지, 날짜 뒤에 점을 찍는지. 예시와 함께.
- **[한글 파일 여러 개를 하나로 붙이는 법](https://valuestools.kr/hwp-merge-guide.html)**
  — 한글에 이미 들어 있는 기능으로 합치는 법과, 쪽 번호·머리말·스타일이 틀어질 때 보는 곳.
- **[PDF 속 표를 엑셀로 옮기는 법](https://valuestools.kr/pdf-table-guide.html)**
  — 돈 안 드는 방법 세 가지와, 스캔본(그림 PDF)일 때 무엇이 다른지.
